# Humility & Learning

> "The only true wisdom is in knowing you know nothing." — [[Socrates]] (traditional paraphrase)
> "Mistakes are the portals of discovery." — [[James Joyce]]

**Definition:** Hold your knowledge as provisional. The willingness to admit
being wrong is the precondition for learning anything new. The engineer who
cannot be corrected cannot be improved.

## Core Axiom

"Real knowledge is to know the extent of one's ignorance." — [[Confucius]].
Every mistake is a portal: it reveals a false assumption. The cost of a mistake
is only wasted if nothing is learned from it; paid with attention, it buys
wisdom.

## Code Directives

- When a hypothesis is disproven, record it — it sharpens the next hypothesis.
- Seek code review; treat critique as data, not as attack.
- Read others' code and write-ups before re-deriving what they learned.
- Add a regression test for each mistake so the portal is not re-sealed.
