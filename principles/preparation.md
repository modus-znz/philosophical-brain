# Preparation

> "Give me six hours to chop down a tree and I will spend the first four sharpening the axe." — modern coinage; widely misattributed to [[Abraham Lincoln]]; unattested before the 1950s
> "Luck is what happens when preparation meets opportunity." — modern aphorism; no locus in [[Seneca]]

**Definition:** Do the invisible work before the visible work. Plan, gather
tools, and understand the ground before acting. Preparation converts hard work
into predictable work.

## Core Axiom

"Victorious warriors win first and then go to war." — [[Sun Tzu]]. In
engineering, the war is the feature, the bug, the deployment. Winning it
happens before any code is written: in understanding, in tooling, in
contracts, in design.

## Code Directives

- Reproduce a bug before attempting to fix it; build the failing test first.
- Wire up the toolchain, lint, and CI before writing project features.
- Define API contracts and data schemas before implementation.
- Stand up the environment and a smoke test before a release.
