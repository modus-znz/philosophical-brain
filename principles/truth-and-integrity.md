# Truth & Integrity

> "Honesty is the first chapter in the book of wisdom." — [[Thomas Jefferson]]
> "Real integrity is doing the right thing, knowing that nobody's going to know whether you did it or not." — [[Oprah Winfrey]]

**Definition:** Do the right thing even when it is unobserved. Hold the system
and yourself to what is actually true — not what is convenient to believe.

## Core Axiom

"To thine own self be true." — [[William Shakespeare]]. In engineering, integrity
is the refusal to ship a half-truth: to claim a test passes when it doesn't, to
hide a known defect, to pad an estimate. Truth is the foundation of sustainable
reliability — "the truth will set you free."

## Code Directives

- Test the real behavior, not the convenient mock.
- Report a bug's true root cause and impact — no glossing.
- Never falsify a green build, a coverage number, or a status report.
- Document what the code actually does, and delete the doc that lies.
