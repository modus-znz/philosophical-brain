# Collaboration & Teamwork

> "If you want to go fast, go alone. If you want to go far, go together." — African proverb
> "None of us is as smart as all of us." — [[Ken Blanchard]]

**Definition:** Leverage the compounding intelligence of the group. The best
engineering decisions survive the scrutiny of diverse minds; the best systems
are built by people who communicate.

## Core Axiom

"Umoja ni nguvu, utengano ni udhaifu." (Unity is strength, division is
weakness.) — Swahili proverb. A single viewpoint is a single failure mode.
Review, pairing, and shared context convert individual error into collective
reliability.

## Code Directives

- Review every non-trivial change; four eyes on the contract.
- Write for the next reader, not the next release — shared code is shared context.
- Document the "why" in commit messages and comments, not just the "what."
- When blocked, reach out — many blockers dissolve under a second viewpoint.
