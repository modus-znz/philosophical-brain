# Content Theme Tree — Timeless Wisdom Channel

> Hand-curated, not generated. `render_persona.py` splices this file into the
> end of `~/.claude/knowledge/wisdom-quotes.md` byte-for-byte. It serves the
> Timeless Wisdom video project, not the session persona, so its groups are
> themes rather than session moments.

> A second growth ring on this library, distinct from the session-moment groups above. Those groups are keyed to *what Claude is doing*; this tree is keyed to *what a viewer is feeling* — the actual thematic branches a faceless wisdom channel scripts from. One quote + one theme per short. Traditions are mixed within each branch rather than siloed, so a script can pair a Stoic line with a Swahili proverb making the same point. Expand this tree over time — new branches, deeper pools per branch — rather than widening the session-moment groups above, which stay scoped to dev-session use.
